# Observability Setup Guide

Compliant with [.ai/AI-GUIDELINES.md](../../.ai/AI-GUIDELINES.md) v3b99cda02934ad7cdc87310613fb7faac37a49f19d9620106e96e73cacb6bb8e

> Establish a consistent local observability stack so engineers can evaluate bootstrap health, parity drift, and CI readiness signals before opening a pull request.

## 1. Prerequisites

- Prometheus `>=2.53.0`
- Grafana OSS `>=11.2`
- Podman Desktop `>=5.7.0` (preferred) or Docker Desktop `>=4.33` for running optional exporters
- PHP 8.5.x via Herd (native profile) and Bun `>=1.1.0`

| Component | Installation Command (macOS) | Installation Command (Ubuntu) | Notes |
|-----------|-----------------------------|--------------------------------|-------|
| Prometheus | `brew install prometheus` | `sudo apt install prometheus` | Windows users: `choco install prometheus` |
| Grafana OSS | `brew install grafana` | `sudo apt install grafana` | Windows users: `choco install grafana` |
| Node Exporter *(optional)* | `brew install node_exporter` | `sudo apt install prometheus-node-exporter` | Useful for host metrics during parity analysis |

> **Herd integration:** Keep Herd’s PHP runtime as the default for the native profile. Run Prometheus and Grafana outside Herd, but store dashboards in `docs/base-platform/observability/grafana/` to keep parity with the repository.

## 2. Prometheus Configuration

1. Copy the baseline scrape configuration generated by **T040A**:

```bash
cp config/prometheus/base-platform.yml ~/.config/base-platform/prometheus.yml
```

2. Review the `scrape_configs`:
   - `bootstrap_runner`: scrapes `http://127.0.0.1:9600/metrics`
   - `parity_checker`: scrapes `http://127.0.0.1:9601/metrics`
   - `profile_validator`: scrapes `http://127.0.0.1:9602/metrics`
3. Start Prometheus:

```bash
prometheus --config.file ~/.config/base-platform/prometheus.yml --storage.tsdb.path ~/.cache/base-platform/prometheus
```

4. Validate targets via `http://localhost:9090/targets`.
5. Run the bootstrap workflow to populate metrics:

```bash
php artisan platform:bootstrap --profile=${BASE_PLATFORM_PROFILE}
```

6. Confirm timeseries exist:
   - `base_platform_bootstrap_duration_seconds`
   - `base_platform_parity_result_total`
   - `base_platform_environment_validation_failures_total`

## 3. Grafana Dashboards

1. Start Grafana (foreground):

```bash
   grafana-server
```

   Or as a service (`brew services start grafana` / `sudo systemctl start grafana-server`).
2. Access `http://localhost:3000/` (default credentials `admin/admin`).
3. Add a Prometheus data source pointing to `http://localhost:9090`.
4. Import dashboard JSON templates from `docs/base-platform/observability/grafana/`:

- `bootstrap-overview.json`
- `parity-drift.json`
- `ci-health.json`

5. Verify key panels:

- **Bootstrap SLA**: 45-minute timer vs. actual duration (`SC-001`).
- **Parity Drift Alerts**: counts per profile.
- **Nightly CI Reliability**: ratio of successful nightly runs vs. failures.

6. Exporters optional: enable Node Exporter for host-level metrics (CPU/memory) to validate parity under load.

## 4. Validation Workflow

| Step | Command | Expected Outcome |
|------|---------|------------------|
| 1 | `php artisan platform:bootstrap --profile=native` | Prometheus captures bootstrap duration metrics |
| 2 | `php artisan platform:parity-check --profile=native` | Grafana parity dashboard updates without alerting |
| 3 | `php artisan platform:validate-profiles --all` | Validation metrics surface and QA can download artifacts |
| 4 | Review Grafana dashboards | No SLA breaches; alerts configured per dashboard notes |

## 5. Troubleshooting

- **Missing metrics**: Ensure exporters start with the Laravel commands (`--metrics-port` flags). Check `storage/logs/base-platform.log`.
- **Grafana cannot reach Prometheus**: Confirm Prometheus is listening on `http://localhost:9090` and that no firewall blocks the port.
- **Dashboard import errors**: Validate JSON files are UTF-8 encoded and match Grafana version `>=11.2`.
- **Herd conflicts**: Verify PHP CLI path for Prometheus exporters (`which php`) still points to Herd when using the native profile.
