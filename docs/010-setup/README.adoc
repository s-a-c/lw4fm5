== 2. Setup Order and Workflow

=== 2.1. Recommended Setup Order

For new installations, follow this order:

. **PHP Runtime** (xref:030-php-runtime.adoc[php-runtime.adoc])
   .. Install PHP 8.5+
   .. Verify required extensions
   .. Configure PHP settings

. **Laravel Core** (xref:040-laravel-core.adoc[laravel-core.adoc])
   .. Verify Laravel installation
   .. Configure environment file
   .. Generate application key
   .. Set up database (SQLite recommended for development)
   .. Enable API routes and broadcasting

. **Database Setup** (xref:040-laravel-core.adoc#database-configuration[laravel-core.adoc])
   .. Configure SQLite for development
   .. Enable WAL mode (recommended)
   .. Run migrations

. **Frontend Build** (xref:130-frontend-build.adoc[frontend-build.adoc])
   .. Install Bun
   .. Install frontend dependencies (`bun install`)
   .. Build assets (`bun run build`)

. **Livewire Ecosystem** (xref:050-livewire-ecosystem.adoc[livewire-ecosystem.adoc])
   .. Configure Livewire
   .. Set up Volt
   .. Configure Flux Pro (if using)

. **Packages** - Install and configure remaining packages as needed:
   .. xref:060-admin-panel.adoc[Filament Admin Panel]
   .. xref:070-auth-security.adoc[Authentication & Security]
   .. xref:080-queue-monitoring.adoc[Queue & Monitoring]
   .. xref:090-observability.adoc[Observability Tools]
   .. xref:100-spatie-packages.adoc[Spatie Packages]
   .. xref:110-search-analytics.adoc[Search & Analytics]

. **Development Tools** (xref:120-development-tools.adoc[development-tools.adoc])
   .. Set up debugging tools
   .. Configure code quality tools
   .. Set up testing framework (Pest 4)
   .. Install Playwright browsers

=== 2.2. Quick Setup Commands

For experienced developers, here's a condensed setup:

[source,bash]
----
# 1. Install PHP dependencies
composer install

# 2. Set up environment
cp .env.example .env
php artisan key:generate

# 3. Set up database (SQLite)
touch database/database.sqlite
php artisan migrate

# 4. Install frontend dependencies
bun install
bun run build

# 5. Install Playwright browsers (for testing)
bunx playwright install --with-deps
----

=== 2.3. Verification Checklist

After setup, verify:

* [ ] PHP 8.5+ installed and configured
* [ ] Laravel application key generated
* [ ] Database connection working
* [ ] Frontend assets building
* [ ] All migrations run successfully
* [ ] Tests passing (`php artisan test`)

== 7. Package Update Strategy

=== 7.1. Stable Packages

For packages with stable versions (e.g., `^12.36`, `^4.0`):

[source,bash]
----
# Update all stable packages
composer update

# Update specific package
composer update laravel/framework

# Update frontend dependencies
bun update
----

**Best Practices:**
* Review changelogs before updating
* Test after updates
* Update packages regularly for security patches

=== 7.2. Development Packages

For packages using development versions (e.g., `^5.x-dev`, `dev-master`):

[source,bash]
----
# Update development packages (careful!)
composer update filament/filament laravel/folio livewire/volt

# Update to latest commit
composer update laravel/folio --prefer-source
----

**WARNING**: Development packages may have breaking changes. Always:

* Check the package's changelog or commit history
* Test thoroughly after updates
* Consider pinning to specific commits if stability is critical
* Update one package at a time to isolate issues

=== 7.3. Update Verification

After updating packages:

[source,bash]
----
# Run tests
php artisan test

# Check for deprecated code
composer analyse

# Format code
composer cs-fix

# Check frontend builds
bun run build
----

=== 7.4. Version Constraints

The project uses different version constraints:

* **Stable**: `^12.36` - Allows minor updates (12.36, 12.37, etc.)
* **Development**: `^5.x-dev` - Allows any development version
* **Specific**: `dev-master` - Uses latest master branch

See xref:020-overview.adoc#version-constraints[overview.adoc] for details.

== 8. CI/CD Integration

=== 8.1. GitHub Actions Workflows

The project includes GitHub Actions workflows in `.github/workflows/`:

* **tests.yml** - Runs PHP tests, static analysis, and browser tests
* **browser-tests.yml** - Dedicated browser testing workflow

=== 8.2. CI/CD Setup

The workflows automatically:

* Set up PHP 8.5
* Set up Bun and Node.js
* Install dependencies (Composer and Bun)
* Configure Flux Pro authentication from secrets
* Run tests and static analysis
* Build frontend assets

=== 8.3. Required Secrets

For CI/CD to work, configure these GitHub secrets:

* `FLUX_USERNAME` - Flux Pro username
* `FLUX_LICENSE_KEY` - Flux Pro license key

=== 8.4. Local Testing

Test CI/CD workflows locally using https://act.sh[act] or by running the commands manually:

[source,bash]
----
# Install dependencies
composer install --no-interaction --prefer-dist --optimize-autoloader
bun install

# Run tests
php artisan test

# Run static analysis
composer analyse

# Build assets
bun run build
----
